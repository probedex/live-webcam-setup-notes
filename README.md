# in-character

**In Character** is a one-page host guide for tabletop role-playing groups on Discord who want to appear on camera as their characters. It covers session-zero rules (opt-in, adults only, own or licensed art), choosing a look, per-player setup through OBS Virtual Camera, game master tips and recording etiquette.

Every product detail in the guide comes from the public pages of [LiveFaceSwap.io](https://livefaceswap.io/), the example studio. Note for readers in October 2026: that studio's live sessions are not connected yet, while its camera preview already opens for free with no account.

## Files

- `index.html`: the guide. Static HTML with inline CSS, no build step and no JavaScript.

## Publishing

Enable GitHub Pages for this repository with the `main` branch and the root folder as the source. To read it locally, open `index.html` in a browser.

## Suggestions

Open an issue if a setup step has changed or a tip is unclear.

For adults 18+; use only your own face or one you have consent to use.
